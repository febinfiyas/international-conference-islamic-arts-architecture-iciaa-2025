# ICIAA Website — iciaa_website_1

A responsive, single-page conference website for the International Conference on Islamic Arts and Architecture (ICIAA), built with HTML, CSS and JavaScript.

## Project files
- `index.html` — the nine main page sections in the requested order
- `styles.css` — responsive theme and layout
- `script.js` — mobile navigation, committee accordion, active-section tracking and gallery lightbox
- `assets/iciaa-logo.png` — supplied conference logo
- `assets/registration-abstract-qr.png` — supplied submission QR code
- `assets/ICIAA_Conference_Brochure_2025.pdf` — supplied conference brochure

The main sections are exactly: Home page; About us; About the programme; Programme objectives; Event highlights; Guest and Organisers; Gallery; Outcomes and achievements; Contacts and credits.

Paper presentation deadlines, the QR/submission link, publication pathways and registration access are embedded inside “About the programme”, so they do not create additional top-level page sections. Registration fee/charge tables are not displayed.

## Preview
Open `index.html` in a browser or use Live Server in VS Code. For public sharing, upload the `iciaa_website_1` folder to a static hosting service.
